SmartKantin JavaFX - siap run

CARA PAKAI (NetBeans):
1. Ekstrak zip ini.
2. NetBeans: File > Open Project > pilih folder "smartkantin-fx" (ikon cangkir kopi Maven).
3. Tunggu NetBeans selesai mengunduh library (butuh internet, hanya pertama kali).
4. Tekan F6 (Run Project).

Butuh JDK 17 atau lebih baru.
Tanpa NetBeans: buka terminal di folder ini, jalankan: mvn javafx:run

File yang terbentuk saat program berjalan:
- data_kantin.dat     -> hasil serialization (menu + omset)
- log_transaksi.txt   -> log struk (file teks)
